# Support

## Bug reports and feature requests

Use GitHub Issues. Search existing issues first to avoid duplicates.

## Questions and general help

Use the [organization Discussions](https://github.com/orgs/avalon-initiative/discussions) for usage questions and general chat.

## Contributing

See [CONTRIBUTING.md](https://github.com/avalon-initiative/.github/blob/main/CONTRIBUTING.md) for the contributor workflow, and
[SECURITY.md](https://github.com/avalon-initiative/.github/blob/main/SECURITY.md) if you're reporting a vulnerability rather than
a bug.
